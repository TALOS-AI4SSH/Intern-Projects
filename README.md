# INTERN PROJECTS

This repository collects research projects by interns at the TALOS AI4SSH Lab, University of Crete. Each intern has a folder with the notebooks and documentation for their work. [About the TALOS internship program](https://talos-ai4ssh.uoc.gr/training/talos-lab-internships/)

## Projects

| Intern | Project |
| --- | --- |
| [Romain Comapretto](./Romain%20Comapretto/) | [BERT Pre-training and Text Analysis for Ancient Greek](./Romain%20Comapretto/BERT%20Pre-training%20and%20Text%20Analysis%20for%20Ancient%20Greek/README.md) |

Romain's project contains two notebooks. The first trains a BERT model from scratch to predict masked tokens in Ancient Greek text. The second uses a public Ancient Greek BERT to identify parts of speech, predict grammatical features and lemmas, and retrieve passages by meaning.
